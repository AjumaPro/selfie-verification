FastHR Meetings — Mac install (unsigned build)

macOS may say “developer cannot be verified.” That is expected until the
app is Apple-signed and notarized. Do not click “Move to Bin.”

INSTALL
-------
1. Open the .dmg and drag “FastHR Meetings” into Applications.
2. First launch — use one of these:

   A) Control-click (right-click) “FastHR Meetings” → Open → Open again.

   B) System Settings → Privacy & Security → scroll to Security →
      Open Anyway (then confirm).

3. Optional (Terminal) to clear quarantine:
     xattr -cr "/Applications/FastHR Meetings.app"
     open "/Applications/FastHR Meetings.app"

Prefer ZIP? Download FastHR-Meetings-Mac.zip, unzip, then open the .app
the same way (Control-click → Open).
