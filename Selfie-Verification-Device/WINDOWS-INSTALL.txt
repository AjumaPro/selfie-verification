GLICO Platform — Windows install
================================

File: Selfie-Verification-Windows.exe
Type: NSIS installer (64-bit)

Install
-------
1. Download Selfie-Verification-Windows.exe
2. Double-click to run the setup wizard
3. Choose install folder (optional)
4. Finish — desktop and Start Menu shortcuts are created
5. Launch "GLICO Platform"

Windows SmartScreen warning (unsigned build)
--------------------------------------------
Because this installer is not code-signed with a paid certificate,
Windows may show: "Windows protected your PC"

Fix:
1. Click "More info"
2. Click "Run anyway"

Antivirus may also scan the first run; allow the app if prompted.

AUTHENTICATION (required for Image Recognition)
-----------------------------------------------
The Windows app is a **device build**: full KYC / web features **without Meetings**.

On first launch (Image Recognition) you will see three authentication sections:

  • Sign in     — approved staff accounts (email + password)
  • Register    — request an account; stays Pending until a superadmin
                  approves you (Super Admin panel)
  • Admin       — superadmin only (user management). Do not use the
                  staff “Sign in” tab for admin credentials.

What needs login:
  • Image Recognition / Ghana Card KYC  → sign-in required
  • Meetings                            → not in this app (use the website)

Tips
  • Tick “Stay signed in on this device” so the next launch skips login.
  • Internet is required for authentication and KYC API calls.
  • Desktop builds talk to the auth API URL set at installer build time
    (REACT_APP_AUTH_API_URL or REACT_APP_DESKTOP_AUTH_API_URL).

Camera / microphone
-------------------
Allow camera access when Windows or the app asks — required for live selfie capture.

Support
-------
