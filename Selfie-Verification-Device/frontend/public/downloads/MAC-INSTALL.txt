GLICO Life Platform — Mac install (unsigned build)

SIZE: Installer is typically ~80–120 MB. If your DMG is still an old
“Selfie Verification” green app, delete it and download again (hard refresh).

INSTALL
-------
1. Open the .dmg and drag “GLICO Life Platform” to Applications.
2. First open: Control-click (right-click) the app → Open → Open again.
   (Gatekeeper: “developer cannot be verified” is expected for unsigned builds.)
   Or: System Settings → Privacy & Security → Open Anyway.
3. Optional quarantine clear:
     xattr -cr "/Applications/GLICO Life Platform.app"
     open "/Applications/GLICO Life Platform.app"

AUTHENTICATION (required for Image Recognition)
-----------------------------------------------
The Mac app is a **device build**: full KYC / web features **without Meetings**.

On first launch (Image Recognition) you will see three authentication sections:

  • Sign in     — approved staff accounts (email + password)
  • Register    — request an account; stays Pending until a superadmin
                  approves you in Super Admin on the app
  • Admin       — superadmin only (user management)

What needs login:
  • Image Recognition / Ghana Card KYC  → sign-in required
  • Meetings                            → not in this app (use the website)

Tips
  • Tick “Stay signed in on this device” so the app remembers you next open.
  • Internet required for login (auth and KYC talk to the GLICO API).
  • Desktop builds call the auth API at the URL baked in at build time
    (REACT_APP_AUTH_API_URL or REACT_APP_DESKTOP_AUTH_API_URL).

CAMERA
------
Allow camera when macOS prompts — required for live selfie capture.
